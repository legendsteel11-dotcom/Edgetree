엣지트리-Edgetree v1.05
[vs-code 스타일의 폴더 트리뷰 탐색기]

1. 폴더 트리뷰(트리 확장, vs-code 스타일)
   (1) 제목바의 ▲로 전체 폴더를 접고 복원
   (2) 자동접기 - 다른 폴더를 펼쳤을 때 기존의 열린 폴더 자동 닫기 토글
   (3) 속도를 위해 한 번에 표시할 수 있는 폴더 내 아이템 갯수 제한 및 커스텀 기능

2. 도킹및 창모드
   (1) 화면 좌/우(토글)에 도킹 및 분리
   (2) 제목바 드래그로 창모드 전환, 고정핀으로 도킹
   (3) 도킹모드에서 영역 바깥라인의 더블클릭으로 창 크기 자동 핏 및 복원
   (4) 탐색기상태, 창 위치/크기 기억

3. 자동펼침/접힘
   (1) 제목바의 아이콘을 클릭하여 자동 접힘 모드로 전환
   (2) 화면 가장자리에 마우스 이동 시 펼침
   (3) 2가지 방식- 마우스가 떠나면 닫기, 마우스 떠나고 클릭하면 닫기
   (4) 고정핀으로 다시 상시 도킹 모드

4. 기본기능
   (1) 윈도우 시작 시 자동시작 - 토글
   (2) 항상 위에 표시 - 토글
   (3) 트레이 아이콘으로 최소화 전환
   (4) Alt Tab 에 항목 제외

5. 파일관련 기능
   (1) 복수 파일 선택 방지※(Shift +나 박스선택으로 여러 파일 선택은 지원하지 않습니다. 위험하다고 판단.)
   (2) 파일을 바로 vs-code 탐색기 등(외부로)으로 끌어 복사할 수 있음
   (3) 복사/붙여넣기/이름 변경/속성/경로복사/더블클릭으로 열기/프로그램 연결 지원
   (4) 다른 탐색기에서 갱신된 파일 정보 실시간 반영
   (5) 외부에서 내부로 파일 복사

6. 즐겨찾기 기능
   (1) 폴더의 콘텍스트 메뉴로 즐겨찾기 등록
   (2) 즐겨찾기를 클릭하면 바로 펼쳐진 상태로 이동
   (3) 즐겨찾기 중복 클릭 방지
   (4) 즐겨찾기 영역의 위치 변경 기능(상/하)

7. 폴더/파일 아이콘 토글
   폴더/파일 아이콘을 숨기거나 보이게 할 수 있어 더욱 심플하게 화면을 구성할 수 있습니다.

8. 탭 간격 및 행 간격 조정 기능
   각각 좁히거나 늘려 원하는 스타일을 만들 수 있습니다.

9. 정렬 옵션(날짜/이름, 전역 정렬 개별 오버라이드)
   각각의 폴더별로 정렬방식을 개별적으로 설정하고 해제할 수 있습니다. 전역 정렬 개별 오버라이드 기능.

10. 각 항목의 컬러 커스텀 기능
    거의 모든 표시되는 부분의 컬러를 원하는대로 설정할 수 있습니다. 다크/라이트 모드를 지원합니다.

11. 폰트 크기 조정
    Ctrl +-로 폰트 크기 조절, Ctrl+0로 기본크기 환원

12. 설정 내보내기/가져오기/전체 초기화
    사용자의 셋팅을 저장하고 불러올 수 있으며 전체 초기화를 하면 레지스트리도 말끔히 정리됩니다.

13. 한/영 지원
    원하는 언어로 사용하세요.

14. 간단한 폴더 검색 기능
    검색 아이콘 또는 Ctrl + F / E 로 검색창과 탐색기창을 전환하고, 검색결과는 탐색기에서 보거나 아니면 바로 사용할 수 있습니다.
    (\*더 적당하고 좋은 문장으로)
15. 윈도우 디스플레이 확대배율에 맞춤 적용
